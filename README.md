# Model 3 classroom page

A small, desktop-only, single-page recreation of selected [Tesla Model 3](https://www.tesla.com/model3) layouts. It uses semantic HTML, Tailwind CSS through its CDN script, and plain JavaScript. Videos and repeated sections are intentionally omitted.

## Run

View the [website preview](https://dhanushkagunawardhana.github.io/tesla-web-poc/).

Open `index.html` in a modern browser. Internet access is needed for Tailwind's CDN script; the selected Tesla images are stored locally in `assets/images/`.

## Lesson map

1. **HTML:** Identify the `header`, `nav`, `main`, `section`, and `footer` landmarks. Notice headings, links, buttons, image alternative text, and the specs description list.
2. **Tailwind CSS:** Compare utility classes for spacing, colors, typography, and grid layouts. The custom rules in `css/styles.css` handle smooth scrolling, typography, focus outlines, and the hero gradient.
3. **JavaScript:** Read the slide and tab data objects in `js/main.js`. Follow each click handler as it changes text, images, classes, and ARIA state.
4. **Practice:** Add one feature tab, change a grid layout, or add another hero slide and dot.

The images were downloaded from Tesla's Model 3 page on November 6, 2026. They remain Tesla's assets and are included here for this classroom proof of concept. Vehicle figures and offers may change; check Tesla's live page before using them as current product information.
